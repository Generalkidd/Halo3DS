# Integration attribution

Preserve the `New3DS integration additions by Kevin Boggs.` code comments in files listed by `port/n3ds/tools/attribution-files.txt` and the adjacent `Kevin Boggs: <symbol>` comments listed by `port/n3ds/tools/attribution-symbols.txt`. Run `python port/n3ds/tools/check_attribution.py` before committing. When adding a new integration function or class, put a `Kevin Boggs: <symbol>` attribution comment directly above it and add the symbol to the manifest. Keep existing upstream and third party license notices intact.
